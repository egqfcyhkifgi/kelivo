# الذكي العربي - Arabic AI Chat

تطبيق محادثة ذكي باللغة العربية مع دعم تحويل النص إلى كلام وتصميم جميل مع الحركات والتأثيرات.

## المميزات

### 🎯 الميزات الأساسية
- **دعم كامل للغة العربية**: واجهة مستخدم باللغة العربية مع دعم الكتابة من اليمين إلى اليسار
- **تحويل النص إلى كلام**: ميزة TTS متقدمة تدعم اللغة العربية مع إعدادات قابلة للتخصيص
- **تصميم جميل**: واجهة مستخدم عصرية مع ألوان متدرجة وتأثيرات بصرية
- **الوضع الليلي والنهاري**: إمكانية التبديل بين الأوضاع مع حفظ التفضيلات
- **حركات وتأثيرات**: تأثيرات انتقالية سلسة وحركات جذابة

### 🎨 التصميم والواجهة
- تصميم مشابه لـ BuildX مع لمسة عربية
- فقاعات رسائل جميلة مع ظلال وانحناءات
- أيقونات Lucide Icons الحديثة
- خط Cairo العربي الجميل
- ألوان متدرجة وتأثيرات بصرية

### 🔊 ميزات الصوت
- تحويل النص العربي إلى كلام
- إعدادات قابلة للتخصيص:
  - سرعة الكلام
  - نبرة الصوت
  - مستوى الصوت
- أزرار تشغيل/إيقاف الصوت في كل رسالة

### 🎭 الحركات والتأثيرات
- تأثيرات الظهور والاختفاء
- حركات الانزلاق والتكبير
- مؤشر الكتابة المتحرك
- تأثيرات التدرج والإضاءة
- انتقالات سلسة بين الشاشات

## التقنيات المستخدمة

- **Flutter 3.27.1**: إطار العمل الأساسي
- **Dart 3.6.0**: لغة البرمجة
- **Provider**: إدارة الحالة
- **flutter_tts**: تحويل النص إلى كلام
- **google_fonts**: خط Cairo العربي
- **flutter_animate**: الحركات والتأثيرات
- **lucide_icons_flutter**: الأيقونات الحديثة
- **shared_preferences**: حفظ الإعدادات

## هيكل المشروع

```
lib/
├── main.dart                 # نقطة البداية الرئيسية
├── models/
│   └── message.dart         # نموذج الرسالة
├── providers/
│   ├── chat_provider.dart   # إدارة المحادثات
│   ├── theme_provider.dart  # إدارة الثيمات
│   └── tts_provider.dart    # إدارة الصوت
├── screens/
│   └── chat_screen.dart     # شاشة المحادثة الرئيسية
└── widgets/
    ├── app_drawer.dart      # القائمة الجانبية
    ├── chat_input.dart      # مربع إدخال النص
    ├── message_bubble.dart  # فقاعة الرسالة
    └── typing_indicator.dart # مؤشر الكتابة
```

## كيفية التشغيل

### متطلبات النظام
- Flutter SDK 3.27.1 أو أحدث
- Android SDK 21 أو أحدث
- Java 21 أو أحدث

### خطوات التشغيل
1. تأكد من تثبيت Flutter SDK
2. استنسخ المشروع أو قم بتحميله
3. افتح Terminal في مجلد المشروع
4. قم بتشغيل الأوامر التالية:

```bash
flutter pub get
flutter run
```

### بناء APK
```bash
flutter build apk --release
```
